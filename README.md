# 🗄️ SQL Server Backup & Restore App

Một ứng dụng Windows Forms đơn giản, trực quan giúp quản lý, sao lưu (Backup) và phục hồi (Restore) cơ sở dữ liệu SQL Server. 

## ✨ Tính năng nổi bật
* **Đăng nhập linh hoạt:** Hỗ trợ cả `Windows Authentication` và `SQL Server Authentication`.
* **Quản lý tự động:** Tự động lọc và hiển thị danh sách các CSDL của người dùng.
* **Sao lưu (Backup):** 
  * Hỗ trợ tạo Device tự động.
  * Tùy chọn sao lưu nối tiếp hoặc ghi đè.
* **Phục hồi (Restore):** * Liệt kê chi tiết lịch sử các bản sao lưu (Thời gian, người thực hiện, vị trí).

## 🛠️ Công nghệ sử dụng
* **Ngôn ngữ:** C# (.NET Framework)
* **Giao diện:** Windows Forms (WinForms)
* **Cơ sở dữ liệu:** Microsoft SQL Server
